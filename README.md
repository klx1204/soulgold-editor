# 魂金存档修改器 · SoulGold Save Editor

纯前端、完全本地运行的《宝可梦 魂金》网页存档修改器。导入 128 KiB 的 GBA 存档，在浏览器里编辑训练家、队伍、盒子、道具和事件，导出时自动重算全部校验和。

> 支持版本：**SoulGold v1.2.1 汉化版（BX21 盒子格式）**。其他版本/原版存档可能使用不同的 SaveBlock 布局，暂不保证兼容。

## 功能

- **训练家**：名字、性别、公开/里 ID、游戏时间、金钱、游戏币、16 枚徽章、图鉴统计
- **同行队伍**：6 只宝可梦，编辑物种、等级、经验、性格、特性、持有物、招式与 PP、个体值、努力值、亲密度、昵称、球种、太晶属性、相遇数据；按等级自动补全招式、自动重算能力值、全部治疗
- **宝可梦盒子**：21 个盒子 × 30 格，支持新建、复制/粘贴、清空、移入队伍、盒子改名
- **道具**：背包 8 个口袋 + 50 个 PC 道具格；道具搜索、数量编辑、清空
- **事件**：徽章、图鉴发现/捕获、事件 Flags、变量 Vars（支持搜索与手动 ID）
- **校验**：扇区校验和、BX21 存储头、盒子溢出扇区、辅助扇区、队伍/盒子/道具数据范围
- **安全写回**：只写当前存档槽，计数器 +1，另一个槽保留为原始备份；金钱/游戏币/背包数量使用存档密钥重新 XOR 加密

## 使用

1. 在模拟器（mGBA / Delta / Pizza Boy 等）中正常保存，导出 `.sav` 文件（必须是 **128 KiB / 131072 字节**）。
2. 打开网页，把 `.sav` 拖进页面，或点击「导入存档」。
3. 修改后点击「导出修改版」，得到 `原文件名_edited.sav`。
4. 把新文件改回模拟器使用的存档名，覆盖前建议先备份。

> 不要在游戏运行中替换存档文件；先退出游戏/模拟器再替换。

## 校验与写回细节

存档由 32 个 4 KiB 扇区组成：

- 槽 1：扇区 0–13；槽 2：扇区 14–27（物理顺序会轮转，按 footer 的 sector id 重组）
- 扇区 28/29：BX21 辅助记录（盒子尾部 + 名人堂）
- 扇区 30/31：盒子溢出数据
- 每个扇区 footer：`id / checksum / signature / counter`
- 校验和：从扇区数据起始处按 little-endian u32 累加并折叠到 16 位
- BX21 存储头：`magic=BX21`、`version=1`、`payloadLength=43440`、`payloadChecksum` 及其反码
- SaveBlock1 的 `0x349A` 处还嵌着 1944 字节的盒子尾部，导出时会与存储区同步

写回策略：

- 只写当前有效槽（counter 较大的槽）
- 新 counter = 两槽最大值 + 1，确保游戏优先读取修改后的槽
- 另一个槽完全不动，作为回滚备份
- 重新计算 14 个主扇区、盒子溢出扇区、BX21 辅助扇区的校验和

## 中文文本限制

存档里的名字使用双字节自定义字库编码（ASCII 为 1 字节，汉字为 2 字节，`0xFF` 结尾）。本项目内置了约 830 个常用字的映射，来源见致谢；不在字库映射中的字符会显示为 `⟨XXXX⟩`，并且无法直接输入。

- 训练家名字最多 3 个汉字（8 字节）
- 宝可梦昵称最多 5 个汉字（12 字节）
- 盒子名字最多 4 个汉字（9 字节）

如果你有完整的汉化字库/字符表，欢迎补充到 `src/data/charmap.json`。

## 技术栈

- React 19 + TypeScript + Vite
- 纯静态，无后端；所有解析与校验在浏览器内完成
- GitHub Actions 自动部署到 GitHub Pages

## 开发

```bash
bun install
bun run dev      # http://localhost:5173
bun run build    # 产物在 dist/
bun run smoke -- /path/to/save.sav   # 解析 → 修改 → 导出 → 重新解析的冒烟测试
```

数据表由 SoulGold 源码（v1.2.1）和 PokeAPI 中文名生成，生成脚本不在本仓库中；`src/data/*.json` 是生成后的静态数据。
